# SICasino v33 — Blackjack + UI Fix

## Blackjack
- Исправлен расчёт результата через единый серверный `finishBlackjack`.
- Обычная победа: выплата `2.00 × ставка` (ставка входит в выплату).
- Натуральный Blackjack: `2.50 × ставка`.
- Ничья: возврат `1.00 × ставка`.
- Проигрыш: выплата `0`.
- В ответ API добавлены `profit` и `balanceAfter`.
- Финальные результаты Blackjack теперь записываются в историю ставок.

## Интерфейс
- Обновлён Game Center с featured-блоком Blackjack.
- Добавлены рабочие фильтры: Все / LIVE / Быстрые / Стратегия / Дропы.
- В Blackjack добавлены быстрые кнопки номиналов ставки.
- После раунда отображаются ставка, выплата, чистый результат и итоговый баланс.
