# SICO v36 — Mobile/tablet layout + data safety

## Интерфейс
- Фильтры в «Играх» (Все / LIVE / Быстрые / …) больше не сжимаются: текст не налезает друг на друга, ряд прокручивается.
- Длинные ники и заголовки (главная, профиль, чат, списки) переносятся и не вылезают за карточки.
- Профиль на телефоне перестраивается в одну колонку; сетка больше не «уезжает» вправо.
- Заголовок экрана входа («С возвращением») масштабируется под ширину экрана (320–360 px).
- Featured-блок Blackjack на телефоне: иконка не сжимает текст.
- Баланс в шапке обрезается с многоточием, а не ломает шапку.
- Проверено на 320 / 360 / 390 / 768 / 834 px и телефон в ландшафте.

## Сервер и данные
- Автобэкапы SQLite: при старте, каждые 6 ч и при остановке → `data/backups/` (хранится последние 14).
- `npm run backup` — полный переносимый бэкап (БД + аватары + admin.key + manifest с контрольной суммой).
- `npm run restore -- <папка>` — восстановление/перенос; текущие данные не удаляются, а откладываются в `data.before-restore-…`.
- `SICO_DATA_DIR` — можно хранить данные вне папки проекта (чтобы обновление кода никогда их не трогало).
- Корректное завершение: финальное сохранение + бэкап, принудительный выход через 4 с, если соединения зависли.
- `.gitignore`: теперь игнорируется вся `data/` (раньше `sico.sqlite` не был исключён).
