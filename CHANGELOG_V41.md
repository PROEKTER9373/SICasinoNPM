# SICO v41 — управление и промокоды

- Добавлен раздел «Промокоды» в Admin Center: создание, включение/отключение и удаление кодов.
- Награды промокодов: SC, XP или выбранный кейс; лимит применений общий для всех игроков; один игрок может активировать код только один раз.
- Добавлена форма активации промокода в меню «Ещё».
- Удалены системные сообщения о выпадении косметики из общего чата.
- Экран общего чата очищен от истории, достижений, Coin Flip, лидерборда, новостей и сезонных промо-блоков.
- Отключены API кристаллов/осколков, их маркета и крафта; кристаллы не сохраняются в профилях.
- База данных в поставляемом архиве очищена от аккаунтов, сообщений, операций, достижений, ставок, публикаций и старых записей маркета.
