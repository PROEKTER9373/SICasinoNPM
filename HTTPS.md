# Локальный HTTPS

Чтобы браузер на телефоне не показывал предупреждение для SICO, сертификат должен быть доверенным именно на телефоне. Сам HTTPS без доверенного CA это предупреждение не уберёт.

## Windows
1. Установи mkcert.
2. Выполни `mkcert -install`.
3. Узнай IP ноутбука, например `192.168.1.50`.
4. В папке `sico/certs` выполни `mkcert -key-file server.key -cert-file server.crt 192.168.1.50 localhost 127.0.0.1`.
5. Установи созданный локальный CA mkcert на телефон и включи доверие к пользовательскому CA (способ зависит от Android/iOS).
6. Запусти `npm start` и открой `https://192.168.1.50:3000`.

Если сертификатных файлов нет, SICO автоматически остаётся на обычном HTTP.
