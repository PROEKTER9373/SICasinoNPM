# SICO Local — Final

Локальный social-casino playground для игры с друзьями в одной Wi‑Fi сети. Только виртуальные SC, без реальных денег и без обязательного доступа в интернет.

## Что внутри

- Регистрация и вход, bcrypt-хеширование паролей.
- Стартовый баланс каждого нового аккаунта: **150 SC**.
- Сессии + привязка сессии к локальному device ID; IP используется как дополнительный сигнал и для rate-limit.
- Серверная проверка баланса, ставок, выигрышей и результатов игр.
- Защита мутационных запросов от повторной отправки через `X-Request-ID`.
- Crash работает постоянно на сервере, даже без ставок.
- Рулетка работает постоянно на сервере, даже без ставок.
- Кейсы теперь полностью серверные: стоимость, RNG и награда не доверяются браузеру.
- История операций и игровых результатов.
- Daily Drop с серией бонусов.
- Уровни и XP.
- Достижения.
- Список игроков и realtime online count.
- Realtime общий чат с ограничением длины и экранированием в интерфейсе.
- SICO Assistant с локальными подсказками.
- Темы профиля: Graphite / Ice / Violet / Lime.
- Аватар до 25 МБ.
- Система виртуальных займов: долг = сумма + 25%, хранится отдельно от баланса.
- Одна поддержка проекта на аккаунт.
- Toast-уведомления и мобильная навигация.
- Отдельная админ-панель с баном/разбаном, балансом, контентом и аудит-логом.

## Запуск

Нужен **Node.js 22+** (используется встроенный `node:sqlite`).

```bash
npm install
npm start
```

Открой на ноутбуке:

```text
http://localhost:3000
```

Чтобы открыть с телефона/другого ПК в той же Wi‑Fi сети:

```text
http://IP-НОУТБУКА:3000
```

Например, если IP ноутбука `192.168.1.50`, адрес будет `http://192.168.1.50:3000`.

Если Windows/macOS спрашивает разрешение для Node.js — разреши входящие соединения в частной/local сети.

## Данные

Данные создаются автоматически в `data/sico.sqlite`, аватары — в `data/avatars/`. Старый `data/db.json`, если он существует, автоматически импортируется при первом запуске в SQLite.

Текущее хранилище — одна сериализованная state-запись внутри SQLite. Для локальной игры с несколькими друзьями этого достаточно; при переходе к большой публичной нагрузке стоит нормализовать данные по таблицам.

## Восстановление аккаунта

Регистрация работает без e-mail: логин + пароль + секретный вопрос и ответ.

Восстановление находится на экране входа: **«Забыли пароль?» → логин → секретный вопрос → ответ → новый пароль**. После правильного ответа сервер выдаёт одноразовый recovery token на 10 минут; сам ответ больше не передаётся на этапе смены пароля. После смены пароля старые сессии аккаунта закрываются. Попытки восстановления ограничены.

## v30 additions

### Google Login
Google login is implemented server-side and is optional. The v31 server reads `GOOGLE_CLIENT_ID` from `.env` (no dotenv package is required).

1. Copy `.env.example` to `.env`.
2. In Google Cloud Console create **OAuth 2.0 Client ID → Web application**.
3. Add the exact origin where SICasino is opened to **Authorized JavaScript origins**, for example `https://your-domain.example` or `http://localhost:3000` for local development.
4. Put the Web Client ID into `.env`:

`GOOGLE_CLIENT_ID=your_google_web_client_id`

5. Restart the server.

The server verifies the Google ID token against Google's `tokeninfo` endpoint and checks the configured audience and verified email before creating or signing into a SICasino account. Existing local accounts are linked by the verified email when possible.

### Plinko
Added a server-authoritative Plinko game at `/api/plinko/play`. The server determines the result and path before the client animation. Multipliers are 0.75x, 1.20x, 1.50x, 2x, 3x, 5x, 10x, then mirrored; a small miss chance pays 0 SC.


## Бэкап и перенос данных (v36)

Все данные игроков лежат в папке `data/`: `sico.sqlite` (аккаунты, балансы, история), `avatars/`, `admin.key`.

- **Автобэкапы** создаются сами в `data/backups/` (старт, каждые 6 часов, остановка). Настройка: `SICO_BACKUP_HOURS`, `SICO_BACKUP_KEEP`.
- **Ручной бэкап (можно при работающем сервере):** `npm run backup` → папка `backups/sico-backup-<дата>/`.
- **Перенос на другой компьютер:** скопируй папку бэкапа, на новом месте `npm install`, затем `npm run restore -- <папка-бэкапа>` (сервер остановлен) и `npm start`.
- **Обновление версии:** копируй новый код поверх, но **не трогай `data/`** — или задай `SICO_DATA_DIR=/путь/вне/проекта`.
